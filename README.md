## 🛠️ Technologies Used

* **HTML5:** Semantic structuring of the content.
* **CSS3:** Styling, layout, and responsiveness.
* **Flexbox:** Flexible layout system for positioning elements.
* **CSS Variables:** Centralization and ease in changing the color palette.
* **VS Code:** Development environment.

## 📖 Learning Journey

This project was built and refined through the following Alura courses:

### 1. HTML and CSS: development environments, file structure, and tags
* **Workload:** 8 hours
* **Challenge:** Create the basic structure of an online portfolio, including a title, paragraph, and image.
* **Solution & Learning:** I set up the development environment in VS Code. I structured the HTML using fundamental tags such as `<html>`, `<head>`, `<title>`, `<body>`, `<h1>`, `<p>`, and `<img>`. I focused on the importance of accessibility by correctly using the `alt` attribute on the `<img>` tag. I learned the solid foundation of how HTML and CSS work together and how to organize the project files.

### 2. HTML and CSS: Classes, positioning, and Flexbox
* **Workload:** 8 hours
* **Challenge:** Style the web page, improving its visual and organization.
* **Solution & Learning:** I used CSS to bring the HTML structure to life. I implemented positioning techniques and explored different fonts to enhance typography. The main focus was applying **Flexbox** to organize elements on the page in a modern and efficient way, making the layout more attractive and structured.

### 3. HTML and CSS: header, footer, and CSS variables
* **Workload:** 6 hours
* **Challenge:** Update the existing project, including a new screen, improving icon display, and implementing navigation.
* **Solution & Learning:** I refined the project by implementing a header and a footer. I explored creating fluid navigation between screens. A key point was the implementation of **CSS Variables**, which allowed centralizing the project's color control, making it easier to change the color palette efficiently. I also ensured that the icons were displayed correctly next to the links.
